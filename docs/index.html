MicroCAD

Documentación técnica del formato .mcad — referencia completa para integración con LLMs, herramientas externas y automatización.

Para LLMs: Esta página describe el formato completo del archivo .mcad. Con este schema podés generar, modificar o analizar dibujos CAD en MicroCAD. La app está en agustin-del-pino.github.io/microcad.

¿Qué es MicroCAD?

MicroCAD es una aplicación CAD 2D ligera que corre completamente en el browser (HTML + Canvas, sin dependencias). Permite dibujar figuras técnicas, organizarlas en capas, exportar a SVG / PNG / PDF y guardar proyectos en formato .mcad.

El formato .mcad es JSON plano, legible y fácil de generar programáticamente o con IA.

Uso con LLMs / IA

El flujo pensado para generar dibujos con IA es:

  • El usuario describe lo que quiere dibujar en lenguaje natural.
  • El LLM genera el JSON completo del archivo .mcad.
  • El usuario guarda el JSON con extensión .mcad y lo abre con MicroCAD → Abrir.
Consejo: En MicroCAD, el botón "Copiar proyecto para LLMs" (panel de capas, parte inferior) copia al portapapeles el schema completo más el JSON del proyecto actual, listo para pegar en cualquier chat de IA.

Estructura raíz del archivo

{
  "version": 4,
  "GRID": 20,
  "unitScale": 1,
  "cfg": { ... },
  "layers": [ ... ],
  "shapes": [ ... ]
}
CampoTipoDescripción
version number requerido Versión del formato. Valor actual: 4.
GRID number requerido Espaciado de la grilla en unidades canvas. Valores típicos: 10, 20, 50.
unitScale number requerido Cuántas unidades base (baseUnit) equivalen a 1 unidad canvas. Ej: 1 significa 1u = 1mm.
cfg object requerido Configuración del proyecto. Ver sección cfg.
layers array requerido Array de capas. Debe tener al menos una.
shapes array requerido Array de shapes. Puede estar vacío.

Sistema de coordenadas

  • Origen (0, 0) en el centro del canvas.
  • Eje X crece hacia la derecha.
  • Eje Y crece hacia abajo (convención screen/canvas).
  • Las unidades son unidades canvas. Su equivalencia física depende de unitScale y baseUnit.
// Con unitScale=1 y baseUnit="mm":
// 1 unidad canvas = 1 mm
// GRID=20 → cada celda de grilla = 20 mm

// Ejemplo: rectángulo centrado de 100×50 mm
{ "type": "rect", "x": -50, "y": -25, "w": 100, "h": 50, "layerId": 1 }
Consejo para LLMs: Por convención, centrá los dibujos en el origen. Usá el GRID como módulo base para las dimensiones (múltiplos de GRID se alinean perfectamente a la grilla).

Capas (layers)

{
  "id": 1,
  "name": "Capa 1",
  "opacity": 1,
  "visible": true
}
CampoTipoDescripción
idnumberIdentificador único. Los shapes referencian capas por este valor.
namestringNombre visible en el panel de capas.
opacitynumberOpacidad de la capa: 0 (invisible) a 1 (opaco).
visiblebooleanSi es false, la capa no se renderiza ni exporta.

Todo shape tiene el campo layerId que debe coincidir con el id de alguna capa existente.

Configuración del proyecto (cfg)

{
  "projectName": "Mi proyecto",
  "baseUnit": "mm",
  "displayUnit": "mm",
  "bgColor": "#1a1d23",
  "gridColor": "#2d3344",
  "exportBgColor": "#ffffff",
  "exportGridColor": "#d4d4d4"
}
CampoTipoDefaultDescripción
projectNamestring"Sin nombre"Nombre del proyecto.
baseUnitstring"mm"Unidad de medida base: "mm", "cm", "m", "km".
displayUnitstring"mm"Unidad de visualización en la UI (puede diferir de baseUnit para conversión automática).
bgColorstring"#1a1d23"Color de fondo del canvas (hex).
gridColorstring"#2d3344"Color de la grilla en canvas (hex).
exportBgColorstring"#ffffff"Color de fondo en exportaciones SVG/PNG/PDF (hex).
exportGridColorstring"#d4d4d4"Color de grilla en exportaciones (hex).

Tipos de shape

Todo shape tiene el campo layerId: number (requerido). Los demás campos dependen del tipo.

line — Línea recta

CampoTipoDescripción
x1, y1numberPunto de inicio.
x2, y2numberPunto de fin.
{ "type": "line", "x1": -100, "y1": 0, "x2": 100, "y2": 0, "layerId": 1 }

rect — Rectángulo

CampoTipoDescripción
x, ynumberEsquina superior-izquierda.
wnumberAncho (positivo).
hnumberAlto (positivo).
{ "type": "rect", "x": -50, "y": -25, "w": 100, "h": 50, "layerId": 1 }

circle — Círculo

CampoTipoDescripción
cx, cynumberCentro del círculo.
rnumberRadio (positivo).
{ "type": "circle", "cx": 0, "cy": 0, "r": 60, "layerId": 1 }

triangle — Triángulo

CampoTipoDescripción
p1, p2, p3{x,y}Los tres vértices.
{
  "type": "triangle",
  "p1": {"x": 0,   "y": -60},
  "p2": {"x": 60,  "y": 40},
  "p3": {"x": -60, "y": 40},
  "layerId": 1
}

arc — Arco de círculo

CampoTipoDescripción
cx, cynumberCentro del arco.
rnumberRadio.
sanumberÁngulo de inicio en radianes (0 = derecha).
eanumberÁngulo de fin en radianes.
ccwbooleanfalse = horario, true = antihorario.
// Semicírculo superior
{
  "type": "arc",
  "cx": 0, "cy": 0, "r": 60,
  "sa": 3.14159, "ea": 0,
  "ccw": false,
  "layerId": 1
}
Ángulos de referencia: 0 = derecha (3h), π/2 ≈ 1.5708 = abajo (6h), π ≈ 3.1416 = izquierda (9h), 3π/2 ≈ 4.7124 = arriba (12h).

poly — Polilínea / Polígono

CampoTipoDescripción
pts{x,y}[]Array de vértices (mínimo 2).
closedbooleantrue = polígono cerrado, false = polilínea abierta.
// Estrella de 4 puntas (polígono cerrado)
{
  "type": "poly",
  "pts": [
    {"x": 0, "y": -80}, {"x": 20, "y": -20},
    {"x": 80, "y": 0},  {"x": 20, "y": 20},
    {"x": 0, "y": 80},  {"x": -20, "y": 20},
    {"x": -80, "y": 0}, {"x": -20, "y": -20}
  ],
  "closed": true,
  "layerId": 1
}

ruler — Regla de medición

Igual que line pero renderiza la medida de distancia sobre el segmento. Usa unitScale y displayUnit para formatear el valor.

{ "type": "ruler", "x1": -100, "y1": 80, "x2": 100, "y2": 80, "layerId": 1 }
// → muestra "200.0 mm" (con unitScale=1, displayUnit="mm")

ground — Línea de terreno / apoyo

Línea con sombreado diagonal en la dirección "suelo" (símbolo de apoyo fijo en ingeniería).

{ "type": "ground", "x1": -120, "y1": 60, "x2": 120, "y2": 60, "layerId": 1 }

angledim — Acotación de ángulo

CampoTipoDescripción
vx, vynumberVértice del ángulo.
p1x, p1ynumberExtremo del primer brazo.
p2x, p2ynumberExtremo del segundo brazo.
// Ángulo de 90° con vértice en el origen
{
  "type": "angledim",
  "vx": 0,  "vy": 0,
  "p1x": 100, "p1y": 0,
  "p2x": 0,   "p2y": -100,
  "layerId": 1
}

La app calcula y muestra el ángulo formado automáticamente.

group — Grupo de shapes

CampoTipoDescripción
childrenshape[]Array de shapes anidados (cualquier tipo, incluyendo otros grupos).
{
  "type": "group",
  "layerId": 1,
  "children": [
    { "type": "circle", "cx": 0, "cy": 0, "r": 40, "layerId": 1 },
    { "type": "line", "x1": -40, "y1": 0, "x2": 40, "y2": 0, "layerId": 1 }
  ]
}

Ejemplo completo — Perfil de viga I

{
  "version": 4,
  "GRID": 20,
  "unitScale": 1,
  "cfg": {
    "projectName": "Perfil viga I",
    "baseUnit": "mm",
    "displayUnit": "mm",
    "bgColor": "#1a1d23",
    "gridColor": "#2d3344",
    "exportBgColor": "#ffffff",
    "exportGridColor": "#d4d4d4"
  },
  "layers": [
    { "id": 1, "name": "Perfil",   "opacity": 1, "visible": true },
    { "id": 2, "name": "Cotas",    "opacity": 1, "visible": true }
  ],
  "shapes": [
    // Ala superior (80×10 mm)
    { "type": "rect", "x": -40, "y": -60, "w": 80, "h": 10, "layerId": 1 },
    // Alma (10×100 mm)
    { "type": "rect", "x": -5,  "y": -50, "w": 10, "h": 100, "layerId": 1 },
    // Ala inferior (80×10 mm)
    { "type": "rect", "x": -40, "y": 50,  "w": 80, "h": 10,  "layerId": 1 },
    // Cota de ancho total
    { "type": "ruler", "x1": -40, "y1": 80, "x2": 40, "y2": 80, "layerId": 2 },
    // Cota de alto total
    { "type": "ruler", "x1": 60, "y1": -60, "x2": 60, "y2": 60, "layerId": 2 }
  ]
}
Nota: Los comentarios (// ...) son solo ilustrativos — el JSON real no admite comentarios. En el archivo final, eliminá los comentarios.
